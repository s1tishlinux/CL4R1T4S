## How to Download These Resources:

### Method 1: Browser "Save as PDF"
1. Open any documentation website
2. Use Chrome/Edge: Print → Save as PDF
3. Save to `/books/` folder

### Method 2: Official Downloads
Many official docs provide PDF downloads:
- Kubernetes: `kubectl get --raw /openapi/v2 > k8s-api.json`
- Python documentation: https://docs.python.org/3/download.html

### Method 3: Academic Papers
1. Visit https://arxiv.org/
2. Search for topic (e.g., "RAG systems", "Agentic AI")
3. Download PDF directly
4. Organize in `/books/` by category
