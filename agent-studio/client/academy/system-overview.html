🤖 7 Specialized AI Agents (LangGraph)

Multi-agent workflow powered by LangGraph for advanced RAG queries:

🎯
1. Router Agent
Classifies query intent (factual, analytical, comparison, howto, troubleshooting, code generation, conceptual) and detects target technical role.
🔀
2. Decomposer Agent
Breaks complex queries into manageable sub-queries for multi-step reasoning and comprehensive answers.
🔍
3. Retriever Agent
Hybrid retrieval using Dense embeddings + BM25 sparse search with Reciprocal Rank Fusion (RRF) combining both methods.
⚡
4. Reranker Agent
Cross-encoder reranking (ms-marco-MiniLM-L-6-v2) for precision boost. +20% recall improvement, +17% precision gain.
✅
5. Grader Agent
Evaluates document relevance to query. Filters out irrelevant results (threshold: 0.3). Quality control before generation.
📝
6. Generator Agent
Synthesizes comprehensive answers from retrieved context with proper citations [1], [2], etc. Template-based or LLM-powered.
🔬
7. Evaluator Agent
Detects hallucinations, verifies groundedness (>80% = APPROVED). Confidence scoring and quality control for generated answers.
