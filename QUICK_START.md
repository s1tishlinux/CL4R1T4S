# ⚡ Quick Start - 30 Seconds to Full System Access

## 🚀 Step 1: Start Everything (5 seconds)

```bash
./start_all.sh
```

## 🌐 Step 2: Open Your Browser (5 seconds)

```
http://localhost:3300
```

## 🎯 Step 3: Click a Card (5 seconds)

You'll see **3 prominent colorful cards**:

### 🎯 Purple Card - Unified Multi-Role Dashboard
**Click to:** Query 11 databases simultaneously  
**Use for:** Cross-domain questions (DevOps + AWS + MLE + MLOps, etc.)

### 🗺️ Green Card - System Architecture Overview
**Click to:** View complete system map  
**Use for:** Understanding the 11 databases and 7 agents

### 📊 Orange Card - Original RAG Dashboard
**Click to:** Deep database inspection  
**Use for:** SQL queries and schema exploration

---

## 💡 That's It!

You now have:
- ✅ All 11 role-based vector databases running
- ✅ Unified query interface
- ✅ System overview dashboard
- ✅ Database inspection tools
- ✅ 7 LangGraph agents ready

## 🎓 First Query Example

1. Click **🎯 Purple Card** (Unified Dashboard)
2. Check: ✓ DevOps, ✓ AWS Cloud, ✓ Kubernetes
3. Type: "How to deploy containers to AWS ECS?"
